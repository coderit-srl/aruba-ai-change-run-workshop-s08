# Istruzioni di progetto

Repo personale per l'AI Bootcamp — Data Center Operations. Si lavora sul sandbox NovaDC, un
finto provider di hosting: tutti i dati sono sintetici.

- Gli indirizzi dei servizi sono in `.env`. Non scrivere hostname nei file: usare le variabili.
- Il token del ticketing non va in nessun file del repo.
- Contenuti, commenti e messaggi di commit in italiano; nomi tecnici in inglese.
